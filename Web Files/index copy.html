Hi! This is our home automation website. In the navigation bar above, select "WEBCAM" to access a live feed from the webcam, select "INFO" for contact info for the people behind the project. To return back to this page, select "HOME". The webcam device is based on the OV2640 CMOS image sensor module, which is controlled by and sends data to an ATSAM4S8B, which prompts an ESP-32 to transmit images over the web.
